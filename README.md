# Lending-Club-Visualization

Sales & Profitability Analysis Dashboard (Tableau)

Overview

This project analyzes quarterly sales and profitability data for a large retail chain to uncover what drives performance across product lines and regions. The goal is to identify underperforming areas, highlight opportunities for improvement, and present insights in a clear, interactive format.

 Key Objectives

Evaluate overall sales and profit trends across products and regions

Identify high-performing categories and areas needing improvement

Provide stakeholders with actionable, data-driven insights

Tools & Technologies

Tableau Desktop

Excel / CSV data files

Data storytelling & dashboard design

What I Built

Interactive Tableau visualizations exploring product sales and profitability

Regional performance maps to highlight geographic trends

A clean, executive-friendly dashboard summarizing key findings

A Tableau Story presenting insights, recommendations, and next steps

Published version accessible online for remote team collaboration

Results

This project provides a clear, actionable view of sales performance, enabling teams to explore the data, understand trends, and take informed steps to improve profitability across product lines.
